# RadarStop

Ультралегкий та максимально продуктивний Android-додаток (MVP) у форматі фонового сервісу (Foreground Service) для виявлення камер фіксації швидкості (радарів) у реальному часі.

Додаток розроблено на **нативному Android SDK (Kotlin)** без використання сторонніх бібліотек (Google Play Services, Room DB, WorkManager, Retrofit тощо), що забезпечує:
- ⚡ **Розмір APK:** **~149 КБ** (при ліміті < 1 МБ).
- 🧠 **Використання RAM:** **< 20 МБ**.
- 🔋 **Нульове навантаження на ЦП** під час зупинок авто або відсутності радарів поруч.
- 🚫 **Без інтерфейсу (No Activity UI):** Додаток запускається у фоні та керується через сповіщення у шторці.

## 🚀 Автоматична збірка APK & Крос-платформенність

Для швидкої та автоматичної збірки проєкту на будь-якому комп'ютері використайте відповідний скрипт:

### 🪟 Windows:
```cmd
_BUILD_apk_.bat
```

### 🐧 Linux & 🍎 macOS (Універсальний):
```bash
chmod +x _BUILD_apk_.sh
./_BUILD_apk_.sh
```

Скрипти самостійно:
1. Автоматично визначають платформу (Windows / Linux / macOS) та архітектуру процесора (x86_64 / ARM64).
2. Сканують ПК на наявність Android SDK, а при його відсутності — завантажують портативні **Android Command-Line Tools** у папку `.android-sdk`.
3. Налаштовують портативні **OpenJDK 17** та **Gradle 8.7**.
4. Використовують спільний проектний ключ **`app/keystore/debug.keystore`**, що гарантує **100% однаковий цифровий підпис APK** при збірці з будь-якого ПК для безпроблемного оновлення без видалення.
5. Компілюють проєкт і копіюють готовий підписаний **Release APK** у корінь проєкту під назвою:
   `RadarStop_yy.MM.dd_HHmm.apk`

## 🛠️ Архітектурні Модулі

1. **Точка входу та Дозволи (`SplashActivity`)**:
   - Прозора стартова Activity (`Theme.Transparent`).
   - Перевіряє дозволи на геолокацію та сповіщення.
   - Запускає `RadarForegroundService` та показує Toast `RadarStop Active`.

2. **Головний Сервіс та Сповіщення (`RadarForegroundService`)**:
   - Постійне сповіщення у шторці: `Active. Cameras: X nearby / Y total`.
   - Кнопка **"Help"** для відкриття екрана довідки та **"Turn Off"** для зупинки GPS і вивантаження з пам'яті.
   - 1 звуковий сигнал підтвердження при старті сервісу.

3. **Екран Довідки та Керування Логами (`HelpActivity`)**:
   - Відображає зрозумілу довідку для водія англійською мовою.
   - Кнопка **"ADB"**: постійно видима, відкриває вікно логів ADB (`LogViewerActivity`).
   - Чекбокс **"Autostart"**: дозволяє автоматично запускати сервіс при завантаженні смартфона (значення зберігається при перезапуску).
   - Підтримує масштабування тексту жестами (Pinch-to-Zoom).

4. **Вікно Логів ADB та Логування (`LogViewerActivity`, `AppLogger`)**:
   - Чекбокс **"Logging"**: розташований у вікні ADB прямо під кнопками керування (`Beep`, `Refresh`, `Share`, `Clear`, `Close`).
   - Керує записом логів у файл `radar_app.log` (за замовчуванням вимкнений `false` при старті сервісу).
   - Підтримує масштабування жестами (Pinch-to-Zoom) та відтворення тестових сигналів кнопкою **"Beep"** (`playBeeps(5, 500ms)`).

5. **Автозапуск при старті системи (`BootReceiver`)**:
   - Обробляє події `BOOT_COMPLETED` та `QUICKBOOT_POWERON`.
   - Автоматично піднімає `RadarForegroundService`, якщо в налаштуваннях увімкнено "Autostart".

6. **Синхронізація з Overpass API та Потоковий парсер (`OverpassSyncManager`)**:
   - Завантажує прямокутну сітку Bounding Box **100×100 км** (`lat/lon ± 0.45`).
   - Використовує високошвидкісний потоковий парсер **`android.util.JsonReader`** для читання даних безпосередньо з мережевого потоку `InputStream` (у 2-4 рази швидше, без навантаження на Garbage Collector).
   - Покриває 100% усіх типів камер (`node["enforcement"]` + `node["highway"="speed_camera"]`).
   - Синхронізація блокується, якщо автомобіль стоїть на місці (0 км/год).
   - Тригери синхронізації при русі: минуло **24 години** або автомобіль змістився на **40 км** від початкової точки завантаження.
   - Захист при відсутності Інтернету: у разі відсутності підключення або збою усіх 3 дзеркал (`de`, `kumi`, `fr`) встановлюється пауза повторної спроби **5 хвилин**.

7. **Локальна БД та Уніфікований Пошук (`DatabaseHelper`)**:
   - Збереження камер у SQLite з двоколонковим індексом `CREATE INDEX idx_coords ON cameras(lat, lon)` та прапорцем `is_linear`.
   - Завантаження у RAM-кеш оперативної пам'яті локального квадрата 10×10 км (`lat/lon ± 0.045`).
   - 1-прохідна логіка обчислення найближчої камери для алярму (до 300 м) та перевірки межі `Smart Sleep` (до 3000 м) за один цикл.

8. **Адаптивний GPS Моніторинг та Сплячий Режим Заторів**:
   - **31–70 км/год:** 3 сек (міський режим).
   - **> 70 км/год:** 1 сек (траса) / 15 сек (Smart Sleep > 3 км без камер).
   - **≤ 30 км/год (зупинки та затори):** Перші 3 хвилини після зупинки опитування залишається 3 сек, а після 3 хвилин переходить у **30 сек** (максимальне енергозбереження). Звуки активні лише при > 30 км/год.

9. **Геометричний Контроль Лінійних Зон та Акустичний Радар (`AcousticRadarEngine`)**:
   - Працює через `AudioManager.STREAM_MUSIC` з Audio Focus Ducking для м'якого приглушення музики під час біпу.
   - Супровід 300 м при наближенні та віддаленні від точкових радарів ($\pm 45^\circ$ в лоб і в спину).
   - Геометричний вихід з Лінійних Зон (Average Speed Control): зона автоматично деактивується при геометричному віддаленні від точки входу й відсутності нод виходу попереду.
