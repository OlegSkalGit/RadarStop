# Background Radar Detector (RadarStop)

Ультралегкий та максимально продуктивний Android-додаток (MVP) у форматі фонового сервісу (Foreground Service) для виявлення камер фіксації швидкості (радарів) у реальному часі.

Додаток розроблено на **нативному Android SDK (Kotlin)** без використання сторонніх бібліотек (Google Play Services, Room DB, WorkManager, Retrofit тощо), що забезпечує:
- ⚡ **Розмір APK:** **~135 КБ** (при ліміті < 1 МБ).
- 🧠 **Використання RAM:** **< 20 МБ**.
- 🔋 **Нульове навантаження на ЦП** під час зупинок авто або відсутності радарів поруч.
- 🚫 **Без інтерфейсу (No Activity UI):** Додаток запускається у фоні та керується через сповіщення у шторці.

```bash

```

Скрипти самостійно:
1. Автоматично визначають платформу (Windows / Linux / macOS) та архітектуру процесора (x86_64 / ARM64).
2. Завантажують та налаштовують портативний **OpenJDK 17** (якщо відсутній).

   `app/build/outputs/apk/release/app-release-unsigned.apk`

## 🛠️ Архітектурні Модулі

1. **Точка входу та Дозволи (`SplashActivity`)**:
   - Прозора стартова Activity (`Theme.Transparent`).
   - Перевіряє дозволи на геолокацію та сповіщення.
   - Перенаправляє користувача до налаштувань для виключення з оптимізації акумулятора та дозволу "Дозволити завжди" для фонової геолокації.
   - Запускає `RadarForegroundService` та одразу закривається (`finish()`).

2. **Головний Сервіс та Сповіщення (`RadarForegroundService`)**:
   - Постійне низькопріоритетне сповіщення у шторці (`PRIORITY_LOW`, `.setOngoing(true)`).
   - Містить кнопку **"Turn Off"** для повного вивантаження з пам'яті та зупинки GPS.
   - Оновлює статус у реальному часі: кількість радарів у БД, пошук GPS, швидкість та відстань до найближчого радару.

3. **Локальна БД та Синхронізація Overpass (`DatabaseHelper`, `OverpassSyncManager`)**:
   - Нативний `SQLiteOpenHelper` із просторовим індексом `CREATE INDEX idx_coords ON cameras(lat, lon)`.
   - Зворотнє геокодування країни через Overpass `is_in` та автоматична ротація між 3 дзеркалами (`overpass-api.de`, `overpass.kumi.systems`, `api.openstreetmap.fr`).
   - Завантаження сітки Bounding Box 100x100 км навколо координат водія та автоматичне очищення застарілих даних при перетині кордону країни.

4. **Адаптивний GPS Моніторинг**:
   - **≤ 30 км/год:** Опитування кожні 10 сек (збереження батареї).
   - **31–70 км/год:** Опитування кожні 3 сек (міський режим).
   - **> 70 км/год:** Опитування кожні 1 сек (траса).
   - **Smart Sleep Mode:** 15 сек при високій швидкості, якщо в радіусі 3 км немає жодної камери.

5. **Математика Наближення та Звуковий Радар (`RadarMath`, `AcousticRadarEngine`)**:
   - Формула відносної швидкості наближення: \(V_{\text{approach}} = V_{\text{car}} \cdot \cos(\Delta \alpha)\).
   - Автоматичне відсікання паралельних/перепендикулярних доріг та машин, що стоять.
   - Перевірка азимута камери (±45° зустрічний / попутний напрямок).
   - Динамічний звуковий сигнал через апаратний `ToneGenerator` із приглушенням стороннього аудіо (Audio Focus Ducking).
