# RadarStop

Ультралегкий та максимально продуктивний Android-додаток (MVP) у форматі фонового сервісу (Foreground Service) для виявлення камер фіксації швидкості (радарів) у реальному часі.

Додаток розроблено на **нативному Android SDK (Kotlin)** без використання сторонніх бібліотек (Google Play Services, Room DB, WorkManager, Retrofit тощо), що забезпечує:
- ⚡ **Розмір APK:** **~146 КБ** (при ліміті < 1 МБ).
- 🧠 **Використання RAM:** **< 20 МБ**.
- 🔋 **Нульове навантаження на ЦП** під час зупинок авто або відсутності радарів поруч.
- 🚫 **Без інтерфейсу (No Activity UI):** Додаток запускається у фоні та керується через сповіщення у шторці.

Для швидкої та автоматичної збірки проєкту крос-платформено використайте відповідний скрипт:

### 🪟 Windows:
```cmd

```

### 🐧 Linux & 🍎 macOS (Універсальний):
```bash
chmod +x _BUILD_apk_.sh
./_BUILD_apk_.sh
```

Скрипти самостійно:
1. Автоматично визначають платформу (Windows / Linux / macOS) та архітектуру процесора (x86_64 / ARM64).
2. Завантажують та налаштовують портативний **OpenJDK 17** (якщо відсутній).
3. Завантажують та налаштовують **Gradle 8.7** (якщо відсутній).
4. Компілюють проєкт і копіюють готовий підписаний **Release APK** у корінь проєкту під назвою:
   `RadarStop_yy.MM.dd_HHmm.apk`

## 🛠️ Архітектурні Модулі

1. **Точка входу та Дозволи (`SplashActivity`)**:
   - Прозора стартова Activity (`Theme.Transparent`).
   - Перевіряє дозволи на геолокацію та сповіщення.
   - Запускає `RadarForegroundService` та показує Toast `RadarStop Active`.

2. **Головний Сервіс та Сповіщення (`RadarForegroundService`)**:
   - Постійне сповіщення у шторці: `Active. Cameras: X nearby / Y total`.
   - Кнопка **"ADB"** для відкриття екрану логів та **"Turn Off"** для зупинки GPS і вивантаження з пам'яті.
   - 1 звуковий сигнал підтвердження при старті сервісу.

3. **Синхронізація з Overpass API (`OverpassSyncManager`)**:
   - Завантажує прямокутну сітку Bounding Box **100×100 км** (`lat/lon ± 0.45`).
   - Тригери синхронізації: минуло **24 години** або автомобіль змістився на **40 км** від початкової точки завантаження.
   - Захист при відсутності Інтернету: перевіряється системний статус мережі, у разі відсутності підключення або збою усіх дзеркал встановлюється пауза повторної спроби **5 хвилин**.
   - Таймаут кожного дзеркала: **10 секунд**, затримка між переходом до наступного дзеркала: **5 секунд**.

4. **Локальна БД та RAM-кешування (`DatabaseHelper`)**:
   - Збереження камер у SQLite з просторовим індексом `CREATE INDEX idx_coords ON cameras(lat, lon)`.
   - Завантаження у RAM-кеш оперативної пам'яті локального квадрата 10×10 км (`lat/lon ± 0.045`).
   - Перезавантаження RAM-кешу спрацьовує при зміщенні авто на **4 км** від центру попереднього кешу.

5. **Адаптивний GPS Моніторинг та 3-хвилинний Grace-період**:
   - **31–70 км/год:** 3 сек (міський режим).
   - **> 70 км/год:** 1 сек (траса) / 15 сек (Smart Sleep > 3 км без камер).
   - **≤ 30 км/год (короткі зупинки):** Перші 3 хвилини після зупинки опитування залишається 3 сек, і лише після 3 хвилин переходить у 10 сек. Звуки активні лише при > 30 км/год.

6. **Акустичний Радар over Bluetooth (`AcousticRadarEngine`)**:
   - Працює через `AudioManager.STREAM_MUSIC` з 100% гучністю та Audio Focus Ducking.
   - Логування виявлення камер у радіусі 300 м.

7. **Екран Логів (`LogViewerActivity`, `AppLogger`)**:
   - Кнопка **"Beep"** для відтворення 5 підтверджувальних сигналів кажні 0.5 с.
   - Масштабування жестами (Pinch-to-Zoom) та кнопки `+` / `-`, кнопка **"Share"**.
